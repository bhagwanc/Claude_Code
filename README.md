# Claude Code Commands

A quick reference guide to useful Claude Code slash commands, organized by category.

## 1. Session Management

| Command | Description |
|---|---|
| `/exit` | Closes the current active session. |
| `/resume` | Resumes or switches to another session. |
| `/rename` | Renames the current session for better organization. |
| `/export` | Exports the current conversation history to a file. |

## 2. Communication & Utilities

| Command | Description |
|---|---|
| `/btw` | Asks a side question without adding it to the main conversation context. |
| `/usage` | Displays current token usage and session limits. |
| `/extra-usage` | Provides options for additional usage when limits are reached. |

## 3. Configuration & Settings

| Command | Description |
|---|---|
| `/model` | Changes the AI model being used. |
| `/config` | Opens settings to adjust configuration options. |
| `/permissions` | Manages permissions for tools and actions. |
| `/theme` | Changes the interface appearance. |
| `/voice` | Enables or disables voice input, where supported. |

## 4. Account & Analytics

| Command | Description |
|---|---|
| `/logout` | Logs out of the current Claude Code account. |
| `/login` | Starts the login process. |
| `/stats` | Displays usage statistics and activity streaks. |
| `/insights` | Generates a report about usage and performance. |

## 5. View Available Commands

To view the available slash commands in Claude Code:

1. Open Claude Code in your terminal.
2. Type `/`.
3. Browse the available commands using the arrow keys.

> **Note:** Available commands and their behavior may vary depending on your Claude Code version, configuration, and account. Check the official [Claude Code documentation](https://docs.anthropic.com/en/docs/claude-code/overview) for the latest information.
